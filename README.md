# Telegram Bot for Depression Screening

Учебный Telegram-бот для прохождения тестирования на основе шкалы депрессии Бека и получения результата по итогам теста.

## Возможности

* запуск тестирования через Telegram;
* прохождение теста по шагам;
* выбор одного из четырёх вариантов ответа;
* подсчёт итогового результата;
* интерпретация результата по шкале;
* повторное прохождение теста;
* получение информационных материалов;
* запись результатов тестирования;
* построение статистики результатов.

## Структура проекта

```text
psihbot/
├── becks_depression_inventory.py
├── questions.py
├── statistics.py
├── main.py
├── figure/
├── exp.xlsx
├── log.xlsx
└── README.md
```

* `main.py` — основная логика Telegram-бота;
* `questions.py` — вопросы теста;
* `becks_depression_inventory.py` — расчёт и интерпретация результатов;
* `statistics.py` — работа со статистикой и построение графика;
* `exp.xlsx` — данные эксперимента;
* `log.xlsx` — результаты тестирования.

## Технологии

* Python
* Telegram Bot API
* `pyTelegramBotAPI`
* Excel / XLSX
* обработка и анализ данных
* визуализация статистики

## Важно

Бот предназначен для учебных и демонстрационных целей.

Результат тестирования не является медицинским или психологическим диагнозом. Для профессиональной оценки состояния необходимо обратиться к квалифицированному специалисту.

## Результат

В рамках проекта реализован Telegram-бот с пошаговым тестированием, подсчётом и интерпретацией результатов, сохранением статистики и её визуализацией.
